# 🤖 Personal Chat Assistant

A simple rule-based **Personal Chat Assistant** built with **Python** as part of my Python learning journey.

This project demonstrates the fundamentals of Python by creating an interactive chatbot that responds to predefined user queries through a command-line interface.

---

## 📌 Project Overview

The **Personal Chat Assistant** is a menu-free, conversational chatbot that interacts with users by recognizing predefined keywords and responding with appropriate messages.

The chatbot:

* Greets the user based on the current time
* Personalizes the conversation using the user's name
* Responds to common questions and greetings
* Provides motivational messages and jokes
* Ends the conversation when the user types **"bye"**

---

## ✨ Features

* 👋 Personalized welcome message
* 🌅 Time-based greeting
* 👤 User name personalization
* 💬 Interactive command-line conversation
* 🤖 Rule-based responses using a Python dictionary
* 🔍 Case-insensitive input matching
* 😊 Motivational responses
* 😂 Simple joke feature
* 🚪 Graceful chat termination with **"bye"**

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python --version
```

### Clone the Repository

```bash
git clone https://github.com/mandy0285/Personal-Chat-Assistant.git
```

### Navigate to the Project Folder

```bash
cd Personal-Chat-Assistant
```

### Run the Application

```bash
python main.py
```

---

## 💻 How It Works

When you run the program:

1. Enter your name.
2. Receive a greeting based on the current time.
3. Start chatting with the assistant.
4. Type your questions or greetings.
5. Type **"bye"** to end the conversation.

### Example Questions

* Hi
* Hello
* How are you?
* What is your name?
* What can you do?
* Motivate me
* Tell me a joke
* Bye
