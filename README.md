# 🤖 Personal Chat Assistant

A simple command-line **Personal Chat Assistant** built with **Python** as part of my Python learning journey.

This project demonstrates the fundamentals of Python by creating a rule-based chatbot that interacts with users, responds to predefined questions, and provides a conversational experience through the terminal.

---

## 📌 Project Overview

The **Personal Chat Assistant** is a menu-free, interactive chatbot that communicates with users using predefined responses.

The chatbot is designed to:

* Greet users with a personalized message
* Respond to common questions
* Carry out simple rule-based conversations
* Provide an interactive command-line experience

This project helped me understand how chatbots work using basic programming logic before moving on to more advanced AI-powered chatbots.

---

## ✨ Features

* 👋 Personalized welcome message
* 😊 Interactive conversation
* 💬 Rule-based responses
* 🧠 Predefined question-and-answer logic
* ⌨️ Command-line interface
* 🚪 Graceful exit from the conversation

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python --version
```

### Clone the Repository

```bash
git clone https://github.com/mandy0285/Personal-Chat-Assistant.git
```

### Navigate to the Project Folder

```bash
cd Personal-Chat-Assistant
```

### Run the Application

```bash
python main.py
```

---

## 💻 How It Works

When you run the program:

1. The chatbot greets you.
2. You can type messages or questions.
3. The chatbot responds based on predefined rules.
4. Continue chatting until you choose to end the conversation.
